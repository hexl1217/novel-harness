# 反馈记录目录

> 本目录存放**历史反馈记录**，一条一个文件，按 `{YYYY-MM-DD}-{类型缩写}-{简短描述}.md` 命名。
>
> **流程、模板、类型缩写、`status` 字段定义都在 `.harness/rules/反馈追踪流程.md`** ——
> 那是反馈追踪机制的**唯一实体源**。本文件只负责说明目录约定，不复述流程，
> 避免两处维护时措辞漂移。

---

## 目录内容

| 文件 | 用途 |
|:-----|:-----|
| `template-反馈记录.md` | 记录模板，新建反馈时复制它 |
| `README.md` | 本文件（目录说明） |
| `YYYY-MM-DD-*.md` | 历史反馈记录 |
