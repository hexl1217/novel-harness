## 差距分析

**判定：装置缺失，不是执行不到位。**

v1 的病因逐条如下：

| # | 病因 | 表现 |
|:--|:-----|:-----|
| 1 | **无题眼层** | 七节标题是"补的，和涨的""台账""口径"，是内容概括，不是反讽装置。审计原句只被埋在正文里当引文 |
| 2 | **受害者太清醒、叙事者太善良** | 小周全程无力但正直，老谭全程纯良。讽刺没有燃料——燃料是"共谋"：人开始熟练、开始认同、开始替系统把话说完 |
| 3 | **话术只被引用，没有被使用** | "已加快拨付使用、缴回财政重新安排"在 v1 里是一句被抄写的背景文字。真正狠的写法是让这套话术**真的有用**：能解决问题、能被表扬、能被内化 |
| 4 | **数字没有拉平** | 41.64 亿和 193 元并排出现过，但从未发生"换算"这个动作。数字的暴力靠换算才能落地 |
| 5 | **结尾温和** | "半秒之后，他写完了"是留白式收束，读者得到的是疲惫感，不是被刺到的感觉。讽刺需要一个**冷硬闭合** |
| 6 | **"刺"的密度不足** | 全篇靠气氛和留白撑，缺乏成串的反讽落点；用户说"太简单"，指的是密度而非篇幅 |

**核心误判**：我把"讽刺"当成了一种**语气**（克制、不动声色、留白），而它其实是一套**结构装置**——必须有反讽的机关在运转，读者才会在某个瞬间被扎到。

## 后续执行（2026-09-26）

上述"待确认"第 1 条已由用户直接给出答案，**但答案超出了三个候选派别**——用户说：

> 要改成隐喻，按照朱一旦的一块劳力士的回家路，来进行暗喻，你这样容易被封

即：问题不在文体派别（冷叙 / 夹议 / 荒谬自洽），而在**指向性**。v1/v2《叫号》的写法（制度名称、政策文本、屏幕红字）会被平台判定风险，因此改为**暗喻体**：

| 本 case 当年诊断的装置 | 在《金镯子》里的对应实现 |
|:-----------------------|:-------------------------|
| 公文题眼（节标题取反讽原句） | 节标题改为物件与动作（匣子 / 一个说法 / 一只手 / 回 / 确认书 / 好）——**题眼下沉到物**，不再取政策原句 |
| 共谋弧线 | 保留并加强：谭守义不仅接受，还在末节觉得"办事的人挺好"，共谋从"学会话术"升为"感激程序" |
| 语言下行渗透 | 「走个手续」「自愿配合」「手续要清」「东西归位」由公文体渗进民间口语 |
| 数字拉平 | **弃用**——原作《一块劳力士》的价格递增线也一并弃用；本稿的暴力改由"理由个个正当"承担 |
| 冷硬闭合 | 保留：「念着顺，就是好」 |

**关键教训**：讽刺装置与"指名制度"是**可解耦**的。当年我以为装置的锋芒必须钉在具体政策文本上，事实上一套自足的漂流装置（同一物 N 手、每手理由正当、物归原主、自我说服闭合）在不点名任何制度的前提下可以完整承载同样的讽刺。**风险不在"讽刺得够不够狠"，而在"靶子有没有被拆掉"。**
