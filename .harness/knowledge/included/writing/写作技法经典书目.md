# 写作技法经典书目包

## 定位

本包收录写作与故事创作的经典理论与方法论书目，服务故事结构设计、人物塑造、语言语感和短剧改编。

它与 `webnovel-writing-basic`（网文写作基础包）的分工：

- `webnovel-writing-basic`：**可直接套用的网文实操规则**——黄金三章、章节结构、爽点清单、章尾钩子。
- 本包：**方法论依据与延伸阅读索引**——解释"这些规则为什么成立"，以及遇到复杂问题时往哪本书里找答案。

本包不是规则集，是查找表。当 `plot-ideation`、`plot-review`、`rhythm-review`、`human-linguistics` 的规则不足以回答某类创作问题时，用它定位更深的方法论出处。

## RAG 使用边界

适合：

- 用户问"怎么写小说/怎么学写作"时给出书目与阅读路径。
- 设计人物弧光、故事结构、激励事件、反转与期待链时提供理论依据。
- 诊断"中间塌陷""人物单薄""语言像 AI"时，定位对应的方法论。
- 小说改编短剧时，参考影视编剧的结构工具。
- 给延伸阅读建议。

不适合：

- 替代具体题材包（本包不含题材设定）。
- 替代 `webnovel-writing-basic` 的平台化实操规则。
- 替代本项目已有的 Map 规则（见文末"与项目内规则的配合"）。

## 版权边界

本包只登记**书名、作者、核心方法论的自写概括**，不摘录原书正文，不复制可替代原书阅读的段落。购买/借阅渠道请通过正规平台。

## 二、故事结构派（影视/短剧改编最直接有用）

- **罗伯特·麦基《故事》** — 激励事件、进展纠葛、危机、高潮、结局；对抗力量越强，主角选择越有说服力。续作《对白》《人物》分别专攻台词和角色。
- **布莱克·斯奈德《救猫咪》三部曲** — 15 节拍表（开场画面 / 主题呈现 / 催化剂 / 争论 / 第二幕转折 / B 故事 … 终场画面）；一句话故事公式；用"救猫咪"动作在开场 5 分钟确立主角好感度。
- **克里斯托弗·沃格勒《作家之旅》** — 源自坎贝尔神话学的英雄之旅 12 阶段（平凡世界 / 冒险召唤 / 拒斥召唤 / 跨越门槛 / 试炼 / 深渊 / 奖赏 / 归返）。适合长篇主线与卷结构。**注意**：约瑟夫·坎贝尔《千面英雄》是神话学著作，不是写作教程，常被书单混淆。
- **悉德·菲尔德《电影剧本写作基础》** — 三幕剧范式的定型之作，第一幕/第二幕/情节点的量化位置。
- **约翰·特鲁比《故事写作大师班》** — 22 步故事结构，比麦基更"操作化"，强调"道德论证"与角色网络。
- **詹姆斯·斯科特·贝尔《冲突与悬念》《情节与结构》** — 专治中间塌陷、情节推进无力、悬念不足。

## 三、文学内功派（大师谈手艺）

- **斯蒂芬·金《写作这回事》** — 创作生涯回忆 + 极硬的方法论：每天固定字数、删副词、别用被动词态、写完先冷藏。
- **E.M.福斯特《小说面面观》** — 经典文论。"圆人物 / 扁人物"区分就出自这里，直接对应人物设计。
- **米兰·昆德拉《小说的艺术》**、**伊塔洛·卡尔维诺《新千年文学备忘录》** — 两位大师的小说观，拔高叙事审美上限。
- **多萝西娅·布兰德《成为作家》** — 不讲课，专治写不下去：晨间写作、无意识练习。
- **安妮·拉莫特《关于写作：一只鸟接着一只鸟》** — 心理建设向，轻松好读，适合长期写作心态维护。
- **劳伦斯·布洛克《布洛克的小说学堂》** — 职业作家讲技术细节（视角、场景、改写），非常实在。

## 四、中文语境派（读中文经典，学具体技法）

- **毕飞宇《小说课》** — 拆《促织》《项链》《红楼梦》《故乡》，中文写作者首选。
- **王安忆《小说课堂》** — 复旦十三堂课讲稿，学院派，文本分析深。
- **许荣哲《小说课：折磨读者的秘密》《小说课贰：偷故事的人》** — 台湾作家，方法论极清楚。**新手入门最好用**：目标—阻碍—努力—结果—意外—转弯—结局的七步故事结构。
- **阎连科《发现小说》**、**格非《文学的邀约》** — 当代作家的文学观与小说话语分析。
- **叶圣陶、夏丏尊《文心》**、**老舍《老舍谈写作与阅读》** — 基础文笔训练。
- **曹文轩《小说门》** — 面向创作的文体论，国内高校写作课常用。

## 阅读路径建议

按目标选，不要通读：

```text
写网文、要快速上手      -> 许荣哲《小说课》 + webnovel-writing-basic
做短剧、要结构工具      -> 《救猫咪》 -> 《故事》 -> 《作家之旅》
已有项目、要解决具体问题 -> 按症状查：中间塌陷看贝尔 / 人物单薄看福斯特·麦基《人物》 / 语言像AI看毕飞宇·斯蒂芬·金
想长期提升审美          -> 昆德拉《小说的艺术》 + 卡尔维诺《新文学备忘录》
```
