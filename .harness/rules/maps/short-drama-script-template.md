# 短剧分镜脚本 · 通用模板

> 用途：短剧编剧 Agent 把「小说 → 短剧」改编为可出片的分镜脚本时套用的空模板。
> 来源：由《迷雾民宿》第 1 集分镜脚本（projects/迷雾民宿/短剧改编/分镜脚本-第1集.md）的结构沉淀而成。
> 使用：复制本文件到 `projects/{项目名}/短剧改编/分镜脚本-第N集.md`，按占位符 `{xxx}` 填空；涉及 H3 规范 / 提示词公式 / 摄影词汇时，以 `short-drama-adaptation-map.md`、`short-drama-h3-prompt-format.md`、`short-drama-prompt-glossary.md` 为准。

---

## 头部规格

```text
# AI 短剧改编：《{剧名}》第 {N} 集 · {集名}

> 来源：原书第 {X} 章《{章名}》（{黄金开局 / 章末钩子 / 卷末高潮}）
> 规格：竖屏 9:16，{M} 镜 · {5–8s / 用户指定}（空镜 5s / 叙事 8s）≈ {时长}
> 适配工具：MiniMax H3 模型
> 出图用途：每镜 1 张关键帧 → 锁定人物后图生视频（整集连续成片 / 逐镜独立出片）
```

## 二、资产卡（先资产后分镜）

### ① 角色卡 · {角色名}（{性别/年龄/身份}）

- 主体描述（H3，定妆图锁定项）：`{年龄+体型+发型+五官+服装+神态气质+光线+画质}`
- 外貌·造型细节（定妆图锁定）：{五官 / 发型 / 身形细分}
- 服装·配饰（本集固定，跨镜不可改）：{服装 / 配饰锁定项}
- 本集状态（仅镜头 N–M 追加，勿写入定妆图）：{血迹 / 伤口 / 脏污 / 换装等剧情状态}
- 表情·情绪库（按镜头选词）：{情绪A（镜）→ 情绪B（镜）→ ……}
- 声线·对白语气：(S{n}) {音色 / 语速 / 语气特征}
- 标志性动作：{动作习惯 + 对应镜头}
- 出图一致性要点：定妆图锁定「{关键特征}」，剧情状态只追加不入定妆图
- 负向提示词（定妆图，默认中文）：{通用基线 + 本卡追加（禁血迹 / 伤口 / 换装等剧情状态）}

## 三、MiniMax H3 出图说明

- 分辨率：竖屏 9:16，建议 `1080 × 1920`（更稳）或 `720 × 1280`（更快）
- 每镜生成 1 张关键帧，锁定人物后用于图生视频
- 人物一致性：先在 {镜头 A/B} 出定妆图，再作为参考图注入其余镜头
- H3 提示词按「主体 + 动作 + 环境 + 光线 + 风格 + 画质」组织，主体外貌与角色卡一致

### 负向提示词（关键帧 / 定妆图必带 · 默认中文）

- 通用基线：`模糊，低分辨率，低质量，噪点，透视错误，主体变形，多余肢体，多余手指，手指数量错误，解剖错误，手部畸形，脸部崩坏，五官错位，水印，logo，签名，页角标，乱码文字，错别字，JPEG 伪影，过饱和，色偏，真人实拍照片，2D 平涂，低模粗糙，塑料感皮肤`
- 逐镜写法：每镜「关键帧负向」= 通用基线 + 本镜追加，逗号分隔、不删基线项。
- 风格对齐：写实项目基线可带「卡通，动漫，3D渲染」；3D 动漫 / 二维项目必须改成与目标风格不冲突的负向词（如「真人实拍照片，2D 平涂」）。
- 含字幕 / 字卡镜头：基线禁「乱码文字、错别字、页角标」，不整体禁「文字」。
- 定妆图负向：只写「配饰缺失」，不写具体配饰名，避免锁定项被误伤；血迹 / 伤口等剧情状态入负向。
- H3 视频阶段：H3 六段式 / 三字段均无 negative 段，视频质量约束以文字内联在 `integrated_multimodal_description`（如「无多余肢体与手部畸形，无水印文字」）。

### H3 出片模式（二选一或并行）

- **整集连续成片**：{M} 镜合并为 1 个连续视频，H3 走多镜 I2VA（subject_definitions + summary + retention_analysis + detailed_description 带时间戳 + overall_soundscape + non_diegetic_music）
- **逐镜独立出片**：每镜一段 H3 I2VA 三字段，`[Shot N]` 编号与镜号一致、单镜无时间戳，用该镜关键帧作 `<Picture N>`

## 四、分镜脚本

> 每镜 11 字段：画面 / 景别·构图 / 运镜（类型+幅度+速度）/ 镜内节奏（秒级分拍，对齐整集 H3 时间戳）/ 光线·色调 / 连续性 / 转场·衔接 / 音效（环境—动作—主观分层）/ 台词·字幕 / 关键帧正向 / 关键帧负向（通用基线 + 本镜追加）。钩子点已标 ★。

### 镜头 NN（{时长}）｜{景别·运镜}｜{标题} ★{钩子}

- 画面：{谁 + 在做什么 + 看到什么}。
- 景别·构图：{景别}，{构图}，{焦段}，{机位角度}。
- 运镜：{类型 + 幅度 + 速度}。
- 镜内节奏（0–{N}s）：0–{a}s {动作1}；{a}–{b}s {动作2}；{b}–{N}s {动作3}。
- 光线·色调：{时间段}，{光源}，{光线类型}，{色调}。
- 连续性：{与上一镜承接点 / 道具落位 / 色调演进}。
- 转场·衔接：{硬切 → 镜头 N+1；动作 / 光线 / 音效连续}。
- 音效：环境——{…}；动作——{…}；主观——{…}。
- 台词 / 字幕：`{台词}（说话人）`／`字幕：{屏幕文字}`
- 关键帧正向：{光源 + 光线 + 时间段 + 景别 + 构图 + 焦段/机位 + 镜头类型 + 色调 + 材质 + 主体（角色卡①②外貌）+ 场景 + 情绪 + 风格 + 画质}，竖屏 9:16
- 关键帧负向：{通用基线 + 本镜追加；默认中文}，见第三节「负向提示词」

### 整集连续成片 · H3 多镜 I2VA 提示词

```text
subject_definitions:
<Picture 1> 作为 <Subject 1> 人物外观来源，需保持其面部特征、现代服装与配饰。
<Picture N> 作为 <Subject N> 人物外观来源，需保持其面部特征与服装；{本集状态}仅对应镜头追加，不写入定妆图。
<Subject 1> 表示 Picture 1 中人物（{角色名}），将在视频中行动并开口说话。
…
<Video 1> 不适用。
<Audio 1> 不适用。

summary:
[reference generation + audio reference] 生成一段竖屏{题材}短剧《{剧名}》第{N}集整片连续视频，共{M}镜约{时长}：{一句话剧情}。人物外观参考 Picture N，对白与字幕源自分镜脚本。

retention_analysis:
<Subject 1>（出现于 [Shot X]–[Shot Y]）：fully_preserved - 保持 Picture 1 中人物外观。
…
<Picture N>（人物外观来源）：fully_preserved - 保持该图提供的人物身份、服装和主要视觉特征。

detailed_description:
画面为竖屏 9:16 {风格}悬疑短剧，全片以{基调}为基调，镜头以{运镜风格}为主，以下按 [Shot N] At MM:SS.mmm 时间戳依次推进 {M} 个镜头，每镜动作顺序与分镜「镜内节奏」一致。说话人 ID：{角色}(S1，{音色})，{角色}(S2，{音色})，{画外}(S3，{音色})。
[Shot 1] {景别+运镜}，{画面描述}。
[Shot 2] At {MM:SS.mmm}, {景别+运镜}，{画面描述}，{对白 <d>[Chinese] 原词</d>}，画面叠出字幕「{文字}」。
…（每镜依次，时间戳递增）

overall_soundscape:
{环境声 + 动作声 + 非语言人声的 1–4 句连续段落；不含对白}

non_diegetic_music:
{配器 + 速度 + 力度变化；不写抽象情绪词；无配乐写 N/A}
```

### 逐镜独立出片 · 每镜 H3 I2VA（备选模式）

> 每镜用该镜「关键帧正向」出的关键帧作 `<Picture N>` 参考图；`[Shot N]` 编号与该镜一致；单镜视频内部无时间戳。

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot {N}]) is fully referenced.

integrated_multimodal_description: [Shot {N}] {风格}，{光线}，{景别/机位/运镜}，{主体动作}，{画面文字用"引号"}，{同步画内声}。{风格}，画面清晰锐利，结构比例正常，无多余肢体与手部畸形，无水印文字。
overall_soundscape: {环境声 + 动作声 + 非语言人声}。
non_diegetic_music: {配器 + 速度 + 力度} 或 N/A。
```

（每镜一段，共 {M} 段）

## 七、使用建议

1. **先出定妆图**：用角色卡主体描述 + 卡内定妆图负向各生成 4 张定妆图，锁定后注入整集提示词；每镜「关键帧正向 + 关键帧负向」可直接喂 ComfyUI / H3 出该镜关键帧（整集作参考图 / 逐镜作 `<Picture N>`）。人物一致性遵守「出图一致性要点」。
2. **怪物只做剪影**：首集露形不露脸，用局部 / 剪影替代全貌。
3. **音效大于画面**：恐怖感靠声音撑起，出片后建议图生视频 + 二次配音。
4. **三大钩子**：前 10s / 第 15s / 片尾必须保留；钩子间隔 3–5 镜。
5. **出图参数**：竖屏 9:16；整集走 H3 多镜 I2VA，逐镜走每镜 I2VA。
6. **时长节奏**：空镜 5s、叙事 8s（或用户指定），全片约 {时长}。
