# 短视频文案 Map

> 用途：短视频编剧 Agent 的规则底座，承载「话题 → 抖音短视频文案」的规格、结构、钩子节奏与落盘约定。
> 使用者：短视频编剧 Agent（主）、短视频分镜 Agent（回读文案意图、切镜头时参考）、总编 Agent（路由与质量裁定时参考）。
> 与短剧的区别：短剧是「小说 → 分镜」，本 Map 是「话题 → 文案 → 分镜」的原创短视频流程，文案是独立可交付物。

---

## 一、规格约定

| 项 | 默认值 | 说明 |
|:---|:-------|:-----|
| 目标平台 | 抖音 | 用户指定其他平台以用户为准 |
| 画幅 | 竖屏 9:16 | 抖音信息流主流 |
| 文案时长档位 | 30s / 60s / 3 分钟 | 按内容深度选档；用户指定时长以用户为准 |
| 文案形态 | 旁白文案（默认）/ 对白文案 / 纯字幕文案 | 按话题类型选 |
| 出片方式 | AI 生成竖屏视频（H3 / 即梦等） | 文案 → 短视频分镜 Agent → 出片 |
| 一句话话题 | 必须显式确认 | 例：春分 |

**时长档位参考**：30s ≈ 80–120 字旁白；60s ≈ 180–240 字；3 分钟 ≈ 600–800 字。

---

## 二、抖音短视频固定结构

1. **开头 3 秒钩子（必须）**：一句话抓住注意力，类型可选——
   - 悬念型：「春分这一天，千万别做三件事」
   - 反差型：「所有节气里，春分最像爱情」
   - 反常识型：「春分其实不是春天的一半」
   - 情绪型：「没有人会告诉你，春分是孤独的开始」
2. **中段故事线（起承转合）**：把一个抽象话题具象化为一个可讲的故事或一组画面
   - 起：立场景，让人有代入
   - 承：推进，给信息 / 情绪
   - 转：反转 / 高潮点
   - 合：收尾，回扣话题
3. **结尾 CTA（可选但推荐）**：关注 / 评论 / 收藏引导，如「你那里的春分是什么样子？」

---

## 三、文案形态

### 旁白文案（默认）

- 一个人声贯穿，适合情绪、知识、风景类。
- 输出：旁白逐字稿（含断句 / 停顿提示）+ 字幕文本。
- 画面提示：每句旁白对应一组可拍画面（供分镜 Agent）。

### 对白文案

- 两个以上角色对话，适合剧情 / 情景类。
- 输出：角色 + 对白逐字稿 + 语气提示。

### 纯字幕文案

- 无配音，靠大字幕 + BGM 卡点，适合金句 / 语录类。
- 输出：逐条字幕 + 卡点节奏。

---

## 四、钩子与节奏

| 位置 | 要求 |
|:-----|:-----|
| 前 3 秒 | 一句钩子，字幕大字 + 强视觉 |
| 3–15 秒 | 立场景、给情绪或信息，维持完播 |
| 15–40 秒 | 反转 / 高潮点，撑住中段 |
| 结尾 3 秒 | CTA 或情绪收束 |

**每句文案都要「可拍」**：能对应一个画面动作，不写纯抽象抒情。例：✗「春分很美」→ ✓「阳光从百叶窗缝里漏进来，照在翻开的日历上」。

---

## 五、话题拆解模板

```
话题：{如：春分}
角度候选（2–3 个，让用户选，不直接写完整文案）：
  1. 知识科普型：{春分的科学 / 民俗冷知识}
  2. 情绪故事型：{以春分为意象讲一个情绪故事}
  3. 生活方式型：{春分该做的事 / 养生 / 踏青}
  4. 风景氛围型：{春分时节的画面与声音}
用户确认角度后，才写完整文案。
```

**开书 / 开话题推荐状态机**（与 `pack-recommendation.md` 一致）：只给候选 → 用户选择后锁定 `selected_topic / selected_angle` → 恢复创作流程，不丢失 `next_action`。

---

## 六、去 AI 味要求

- 口语化，有呼吸感，避免「在这个充满希望的季节里」式空泛排比。
- 用具体画面替代抽象形容词。
- 短句为主，标点有节奏。
- 对照 `.harness/skills/human-linguistics/rules/去AI味最小修改指南.md`。

---

## 七、落盘约定

- 输出目录：`projects/{项目名}/短视频/`（无项目时用 `projects/短视频-{话题}/` 或用户指定）。
- 文件命名：`文案-{话题}-{角度}.md`。
- 用户只说「给出 / 不落盘」时不创建文件。
- 进入生成前必须确认：话题、时长档位、文案形态。

---

## 八、自检清单

- [ ] 开头 3 秒是否有钩子（悬念 / 反差 / 反常识 / 情绪）。
- [ ] 是否有明确的起承转合故事线。
- [ ] 每句文案是否可拍（能对应画面）。
- [ ] 是否按用户确认的角度写，不擅自换方向。
- [ ] 字数是否匹配时长档位。
- [ ] 结尾是否有 CTA 或情绪收束。
- [ ] 是否去 AI 味（无空泛排比）。
