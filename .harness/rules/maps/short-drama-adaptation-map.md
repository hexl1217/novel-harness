# 短剧改编 Map

> 用途：短剧编剧 Agent 的规则底座，承载 AI 短剧改编的规格、结构、钩子节奏与落盘约定。
> 使用者：短剧编剧 Agent（主）、总编 Agent（路由与质量裁定时参考）。
> 本文件承载规则细节，Agent 本体保持轻量，只保留身份、流程、路由与硬门禁。

---

## 一、规格约定

| 项 | 默认值 | 说明 |
|:---|:-------|:-----|
| 画幅 | 竖屏 9:16 | 短剧平台主流 |
| 单镜头时长 | 15 秒 | 用户指定其他时长时以用户为准 |
| 单集镜头数 | 12–24 镜 | 约 2–4 分钟，适配平台留存节奏 |
| 单集来源 | 原书 1–2 章 | 优先取「黄金三章」或强钩子章节 |
| 视觉基调 | 写实电影感 | 可随题材调整（悬疑=冷灰，都市=暖调） |

换算参考：15s/镜 → 20 镜 ≈ 5'00"；12 镜 ≈ 3'；24 镜 ≈ 6'。

---

## 二、每集固定结构（三幕钩子）

1. **开场建立（前 3 镜）**：场景 + 人物登场 + 第一个异常信号。
2. **悬念升级（中段）**：信息断档 / 异响 / 规则破坏，每 2–3 镜推进一步。
3. **高潮爆发（倒数 2–3 镜）**：最强冲突点或反转。
4. **片尾钩子（最后 1 镜）**：落在变化、危险、选择或信息打断上，不总结收束。

## 三、三大留存钩子（必须保留）

| 位置 | 钩子 | 作用 |
|:-----|:-----|:-----|
| 前 10 秒 | 环境异变 / 异常信息 | 留住第一屏 |
| 第 15 秒前后 | 恐怖点 / 反转 | 撑住完播率 |
| 片尾 | 未解悬念 / 新危机 | 拉高追更 |

## 四、镜头字段（每镜必须完整）

```text
镜头 XX（15s）｜景别 · 机位 · 运镜｜标题 ★（钩子标注）
- 画面：一句话说清「谁 + 在做什么 + 看到什么」。
- 连续性：与上一镜的承接点（主体/空间/动作/光线是否延续），防跳戏。关键道具必须交代落位：后镜要用到的手机、刀、水桶等，先在前镜让它出现或落位（如「随手放到吧台上」），禁止凭空出现。
- 音效：脚步声 / 呼吸 / 环境底噪 / 提示音，恐怖感优先靠声音。
- 台词 / 字幕：台词用「」，屏幕文字用「字幕：」。
- 关键帧正向提示词：`按提示词公式生成，默认中文`（喂 ComfyUI + MiniMax H3 出图）
- 关键帧负向提示词：`通用基线 + 本镜追加`（默认中文，喂 ComfyUI 出图）。
  - 通用基线：`模糊，低分辨率，低质量，噪点，透视错误，主体变形，多余肢体，多余手指，手指数量错误，解剖错误，手部畸形，脸部崩坏，五官错位，水印，logo，签名，页角标，乱码文字，错别字，JPEG 伪影，过饱和，色偏，真人实拍照片，2D 平涂，低模粗糙，塑料感皮肤`
  - 逐镜追加：本镜专属禁忌（怪物露全脸 / 道其穿帮 / 字幕错字 / 多余人物 / 道具缺失等），逗号分隔接在基线后，不删基线项。
  - 风格对齐：写实项目基线可带 `卡通，动漫，3D渲染`；3D 动漫项目改用 `真人实拍照片，2D 平涂，低模粗糙`，避免与目标风格冲突。
  - 含字幕镜头：只禁 `乱码文字，错别字，页角标`，不整体禁 `文字`。
  - H3 视频阶段：六段式 / 三字段**无 negative 段**，视频质量约束内联在 `integrated_multimodal_description`（如「无多余肢体与手部畸形，无水印文字」）。
- 图生视频提示词（H3 三字段，默认）：`integrated_multimodal_description + overall_soundscape + non_diegetic_music`，按 `short-drama-h3-prompt-format.md` 生成
```

钩子标注规则：★ 常规钩子，★★ 重要悬念，★★★ 全片最强钩子。

## 五、提示词公式（关键帧 / 图生视频）

**关键帧正向提示词公式**（按序组合，按镜头需要选取维度，不硬凑）：

```text
光源类型 + 光线类型 + 时间段 + 景别 + 构图 + 镜头焦段/机位角度 + 镜头类型 + 色调
+ 材质/表面质感 + 主体描述 + 场景描述 + 人物情绪 + 风格化 + 画质尾缀
```

**示例（悬疑夜景·贴门倾听）**：

```text
夜晚，人工光，边缘光，冷色调，特写，中心构图，中焦距，干净单人镜头，
年轻中国女性贴门板倾听、神情紧张，老旧民宿走廊昏暗，斑驳木门粗糙质感，写实电影感，电影画质，竖屏 9:16
```

**图生视频提示词 = H3 三字段（默认）**：

```text
integrated_multimodal_description: [Shot N] 00:00.000, {景别/机位/运镜} + {主体动作} + {画面文字用“引号”} + {同步画内声}
overall_soundscape: {环境声 + 动作声 + 非语言人声总结}
non_diegetic_music: {配乐描述 或 N/A}
```

每镜独立出片时 `[Shot N]` 的 **N 必须等于该镜编号**（第 2 镜写 `[Shot 2]`、第 15 镜写 `[Shot 15]`），禁止整集全部照抄 `[Shot 1]`；字段按 `short-drama-h3-prompt-format.md` 生成，全中文。仅当用户明确要求极简时才用简版「运动 + 运镜 + 音效」。

**选词来源**：`short-drama-prompt-glossary.md` 摄影词汇库，按光源/光线/时间段/景别/构图/焦段/机位/色调/材质/情绪/运镜/风格各维度选词，避免只用"写实电影感"空泛词。

**默认语言**：关键帧正向 / 负向提示词、图生视频提示词一律**中文输出**（MiniMax H3 对中文自然语言支持好）；仅当用户明确要求英文时才出英文。

## 六、人物提示词格式

- 每个主要角色一组，**默认中文正向 / 负向提示词**（MiniMax H3 对中文支持好；用户指定英文时才出英文）。
- 中文正向：年龄 + 体型 + 发型 + 五官特征 + 服装 + 神态气质 + 打光 + 画质。
- 中文负向默认：`模糊，低分辨率，低质量，变形，多余肢体，多余手指，解剖错误，手部畸形，水印，文字，logo，签名，JPEG伪影，过饱和，卡通，动漫，3D渲染`（角色卡可加 `塑料皮肤`，怪物卡加 `全脸，清晰五官`）。
  - 风格对齐：写实项目用上句默认；3D 动漫 / 二维项目把 `卡通，动漫，3D渲染` 换成 `真人实拍照片，2D 平涂，低模粗糙`，并删掉与项目风格冲突的项。
  - 含字幕镜头不整体禁 `文字`，改为 `乱码文字，错别字，页角标`；定妆图负向只写 `配饰缺失`，不写具体配饰名。
- 每集新增角色时，在分镜文档头部补充该角色提示词；已在前期集数锁定的角色复用原文，不重写。
- 建议流程：先出「人物定妆图」锁定形象 → 再喂给视频工具做一致性出片。

## 七、异化生物 / 怪物表现原则

- 首集只做剪影、局部（手 / 轮廓 / 雾中蠕动），不做清晰全貌特写。
- 恐怖感靠「局部 + 声音 + 光线」撑起，不靠血腥特写。
- 后期集数可按剧情逐步解锁全貌，但不做猎奇式展示。

## 八、改编取材规则

- 优先取原书黄金三章、章末钩子、卷末高潮作为单集来源。
- 每集只服务一个核心事件，不塞多线。
- 人名、金手指、关键台词尽量沿用原文，避免改动核心设定。
- 章节名或章末钩子可拆成 1–3 镜，但镜头内信息只保留一个焦点。

## 九、落盘约定

- 输出目录：`projects/{项目名}/短剧改编/`
- 文件命名：`分镜脚本-第N集.md`
- 文档结构：改编定位 → 人物提示词 → ComfyUI 出图说明 → 分镜脚本（每镜含关键帧正向/负向 + 图生视频提示词）→ 使用建议。
- 用户只说「给出/不落盘」时不创建文件；用户说「保存/落盘」时写入上述路径。
- 进入生成前必须确认：剧名、单镜头时长、单集镜头数、目标集数。

## 十、自检清单

- [ ] 每镜 15 秒（或用户指定时长），单集 12–24 镜。
- [ ] 三大钩子（前 10s / 第 15s / 片尾）是否齐全。
- [ ] 每镜画面是「动作 + 可拍信息」，不是心理独白或总结。
- [ ] 关键帧正向提示词按「提示词公式」组合（光源/光线/景别/构图/色调/材质/情绪等维度选词）。
- [ ] 每镜含关键帧正向 + 负向提示词（负向 = 通用基线 + 本镜追加），并含图生视频提示词。
- [ ] 图生视频提示词为 H3 三字段（integrated_multimodal_description / overall_soundscape / non_diegetic_music），中文，画面文字用引号。
- [ ] 多元素运动方向用【】标注，每镜 ≤ 2 个。
- [ ] 正负向提示词 / 人物提示词默认中文，关键特征前后集一致（除非用户指定英文）。
- [ ] 角色卡 / 场景卡 / 道具卡分离，跨镜资产一致。
- [ ] 每镜带「连续性」承接点，无跳戏。
- [ ] 分镜 → 提示词 → 出片按阶段确认（除非用户明说直接给全）。
- [ ] 怪物首集只露形不露脸。
- [ ] 音效列不为空，恐怖感有声音支撑。
- [ ] 关键道具跨镜有落位交代，无凭空出现（如手机先放到吧台、再在吧台来电）。
- [ ] H3 图生视频提示词 `[Shot N]` 编号与该镜序号一致，无整集照抄 `[Shot 1]`。

## 十一、资产卡（先资产后分镜）

> 参照 TE_MAN 成片类 skill 的「资产优先」理念：先锁定可复用资产，再铺分镜，保证角色 / 场景 / 道具跨镜一致。

- **角色卡**：每个主要角色 1 张（外貌 / 服装 / 神态 / 气质，中英双语），跨集复用，不重写。
  - **定妆图只锁定固定外貌**（年龄 / 体型 / 发型 / 五官 / 服装 / 神态气质 / 打光 / 画质），**不写入血迹、伤口、绷带、泥污等本集剧情状态**——这些是「本集状态」而非角色固有外貌，写进定妆图会让每张定妆图固定带同样的血迹，像贴图，且无法跨集复用。
  - 角色若本集有剧情状态（受伤 / 染血 / 脏污 / 换装），在角色卡里单列「本集状态（仅镜头 N–M 追加）」，并在对应镜头的关键帧 / H3 提示词里追加该状态；H3 的 subject 定义只写「保持面部特征与服装」，状态标注为「仅在对应镜头追加，不写入定妆图」。
- **场景卡**：本集核心场景（如「归期民宿前台」「二楼走廊」「老街」），纯环境描述（无人物），含光线基调与主色调；角色卡与场景卡**分离**，不混写。
- **道具卡**：本集关键道具（菜刀 / 手机 / 5L 水桶 / 门），必要时单独出卡，保跨镜一致。
- **输出顺序**：角色 → 场景 → 道具；先在 ComfyUI 出资产定妆 / 定景图，再作为 IP-Adapter / 参考图注入各镜关键帧。

## 十二、阶段确认与交付（分阶段，不一次全出）

> 参照各 skill 的「阶段确认 + 审核清单」：分镜先审，再出提示词，再生成。

- **阶段 1 分镜草案**：只出 画面 / 景别 / 运镜 / 音效 / 台词 / 连续性 的镜头表，等用户确认结构。
- **阶段 2 提示词**：用户确认分镜后，再补 关键帧正向 / 负向 + 图生视频提示词。
- **阶段 3 出片**：用户确认提示词后，再指导 ComfyUI / H3 生成与合成。
- **跳过确认**：用户明说「直接给全」时，一次输出完整分镜 + 提示词。
- **交付类型可选**：用户可选 只出提示词 / 分镜脚本 / 完整创作包（资产卡 + 分镜 + 提示词 + 出片建议）。
