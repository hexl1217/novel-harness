# 短剧摄影提示词词汇库

> 用途：短剧编剧 Agent 生成「关键帧提示词」与「图生视频提示词」时的选词表。
> 来源：SD+MJ 提示词资料库 · 万相提示词指令（文生视频 / 图生视频 / 分镜头规则提炼）。
> 用法：每镜按「提示词公式」从下表各维度选词；避免只用"写实电影感"这种空泛词。
> 选词原则：一个镜头 1-2 个光源 + 1-2 个光线 + 1 个景别 + 1 个构图 + 1 个焦段/机位 + 1 个色调 + 1-2 个材质 + 主体 + 场景 + 运动 + 情绪。

---

## 五、构图

## 六、镜头焦段

## 九、色调

## 十、动态控制 · 运动

奔跑 / 跑步 / 行走 / 转身 / 抬头 / 伸手 / 挥手 / 敲门 / 爬行 / 翻涌 / 蠕动 / 坠落 / 飘散

木质 / 金属 / 混凝土 / 砖石 / 玻璃 / 陶瓷 / 石材 / 纸张 / 皮革 / 织物（麻布/棉/丝绒）/ 塑料 / 锈蚀 / 斑驳 / 哑光 / 高光 / 磨砂 / 粗糙 / 光滑 / 潮湿 / 干燥 / 覆尘 / 苔藓 / 结霜 / 半透明

选词原则：一镜 1-2 个材质词，优先选能强化氛围的（恐怖=潮湿/锈蚀/斑驳，悬疑=冷硬/哑光，温馨=木质/织物）。

## 十六、特效镜头

移轴摄影 / 延时拍摄 / 高速摄影 / 鱼眼畸变

## 十七、图生视频补充规则

- **运动描述**：结合关键帧画面元素描述动态过程，用副词控制速度（「快速地」「缓慢地」）。
- **运镜描述**：明确镜头运动（「镜头推进」「镜头左移」）；镜头不动时写「固定镜头」强调。
- **一致性**：只加运动方向 + 入画动作 + 音效；主体 / 景别 / 位置必须与关键帧一致，不得改画。
- **方向锚定**：多元素运动用【】标空间方向（入画 / 朝镜头 / 左-右 / 上-下），每镜 ≤ 2 个。
